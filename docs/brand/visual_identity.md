# Retail Decision Lab Visual Identity

## Product Style

Retail Decision Lab uses a restrained operations-console identity: neutral surfaces, compact information density, conventional system typography, and color reserved for status and analytical meaning.

## Palette

- Cloud Background: `#F8FAFC`
- Soft Indigo Panel: `#EEF2FF`
- Product Blue: `#2563EB`
- Signal Cyan: `#0891B2`
- Success Mint: `#059669`
- Deep Text: `#0F172A`

## Design Direction

- Bright SaaS dashboard
- Clean glass panels
- Blue/cyan gradient accents
- Soft enterprise analytics feel
- Clear product identity distinct from Fresh Retail Copilot
